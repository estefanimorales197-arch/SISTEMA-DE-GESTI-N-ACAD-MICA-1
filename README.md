# SISTEMA-DE-GESTI-N-ACAD-MICA-1
Sistema de Gestión Académica con Pilas y Colas en C++ - Fase 4
Proyecto desarrollado en C++ para la asignatura de Estructuras de Datos (Fase 4). Implementa el manejo de memoria dinámica mediante nodos y punteros para la gestión de un libro académico y solicitudes de asesoría.

##  Funcionalidades Principales

- **Gestión Académica:** Registro de cursos, grupos, estudiantes, matrículas y calificaciones.
- **Cola de Atención (Queue - FIFO):** Organiza las solicitudes de asesoría en estricto orden de llegada.
- **Pila de Historial (Stack - LIFO):** Almacena el historial de entrada para consultar las solicitudes más recientes.
- **Lista de Solicitudes (LinkedList):** Base de datos dinámica central.

##  Tecnologías Utilizadas

- Lenguaje: **C++**
- Manejo de memoria dinámica (`new`, `delete`, punteros)
- Estructuras de datos lineales (Pilas, Colas y Listas Enlazadas)
